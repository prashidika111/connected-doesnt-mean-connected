## Ever been connected to Wi-Fi but still unable to open a website?
That’s basically what this project is about.
Network connectivity isn't just one thing. DNS can fail while a server is reachable, a gateway can be misconfigured, or a web service can go down even when the network itself is working.
So I wanted to build something that makes these failures easier to understand, rather than just showing connected or disconnected.
The project combines network diagnostics with an interactive browser simulation where you can explore different failure scenarios, step through packet events, and see where things go wrong.
Still an experimental project, but the idea is simple: being connected doesn't mean everything beyond you is reachable.
